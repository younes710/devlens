# DevLens

**A GitHub Profile Explorer built with Next.js, TypeScript, and Hono.**

DevLens is a full-stack web application designed to explore GitHub profiles and public repositories through a clean, modern dashboard.

The project is being built incrementally, with a focus on practical frontend development, API design, and maintainable code.

## Planned Features

- Search GitHub users by username
- Display profile information and public statistics
- Explore public repositories
- Sort repositories by stars
- Handle loading, empty, and error states
- Build a dedicated backend API to communicate with GitHub
- Add search history persistence in a later iteration

## Tech Stack

### Frontend
